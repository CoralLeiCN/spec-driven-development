# Documentation

This directory explains the research basis and recommended repository organization for this spec-driven development template.

## Documents

- [Recommended spec-driven document layout](recommended-layout.md) defines the proposed information ownership, feature packets, decisions, lifecycle, agent workflow, and quality gates for adoption.
- [`agents-template.md`](../agents-template.md) is the lean root instruction contract to copy into a target repository as `AGENTS.md`.
- [Reusable document templates](../templates/README.md) provide concrete feature-spec, research, plan, task, review, validation, and ADR files.
- [Research review and synthesis](research/README.md) compares the four studies and links to their individual reviews.
- [Common patterns across the four studies](research/common-patterns.md) identifies their shared operating loop, unevenly adopted practices, and minimum reusable repository skeleton.
- [GPT-5.6 Sol guidance and practitioner pitfalls](research/gpt-5.6-sol-agent-guidance.md) distinguishes official guidance from anecdotal field reports and traces them to agent guardrails.
- [Agent Rumble review](research/agent-rumble.md) evaluates its documentation authority model and current harness.
- [DeepSeek Harness review](research/deepseek-harness.md) evaluates its agent-oriented documentation hierarchy and mechanical enforcement.
- [OpenAI harness guidance review](research/openai-harness-guidance.md) evaluates the harness-engineering article together with official Codex repository-instruction guidance.
- [Stripe Sync Engine review](research/stripe-sync-engine.md) evaluates its plan-to-code workflow, extensive coding-agent use, executable architecture rules, generated contracts, and limitations as a strict spec-first example.
- [Full Stack FastAPI Template layout review](research/full-stack-fastapi-template.md) summarizes and attributes the default implementation boundaries for a full-stack application with a Python backend.
- The [source reference index](../references/README.md) contains source links and citation metadata only.

The layout and `agents-template.md` become operational only after a target repository adopts and customizes them. The reviews are supporting evidence and do not override an adopted project artifact.
