# Case Studies

Case studies are source-specific evidence. Each document keeps observations,
strengths, limitations, and transferable practices attributable to one project
or publication. Cross-source conclusions belong in [`../reports/`](../reports/README.md).

## Workflow Case Studies

These four studies are the inputs to the cross-case reports:

- [Agent Rumble](agent-rumble.md) — specification-first organization,
  authority, traceability, and validation.
- [DeepSeek Harness](deepseek-harness.md) — documentation ownership, local agent
  instructions, lifecycle, and mechanical enforcement.
- [OpenAI harness guidance](openai-harness-guidance.md) — repository knowledge,
  progressive disclosure, agent legibility, and feedback loops.
- [Stripe Sync Engine](stripe-sync-engine.md) — plan-to-code workflow,
  executable architecture rules, generated contracts, and agent attribution.

They feed the [case study synthesis](../reports/case-study-synthesis.md) and the
[common-pattern report](../reports/common-patterns.md).
